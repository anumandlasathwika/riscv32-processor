# 32-bit RISC-V Processor

A 32-bit RISC-V processor implemented in SystemVerilog with simulation and verification testbenches.

## Overview

This project implements a basic 32-bit RISC-V processor using modular SystemVerilog RTL design.

The processor includes the major components required for instruction execution, including the Program Counter, Instruction Memory, Register File, ALU, Immediate Generator, Decoder, Control Unit, Datapath, and Data Memory.

## Architecture

The processor consists of:

- Program Counter (PC)
- Instruction Memory
- Instruction Decoder
- Control Unit
- Register File
- Arithmetic Logic Unit (ALU)
- Immediate Generator
- Datapath
- Data Memory
- Top-level RISC-V Processor

## Verification

Individual module testbenches and processor-level testbenches are included to verify the RTL design through simulation.

## Technologies

- SystemVerilog
- RISC-V ISA
- RTL Design
- Digital Logic Design
- Simulation and Verification
